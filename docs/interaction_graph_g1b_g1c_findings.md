# G1b / G1c：可达集是真的，但这批录像几乎没有让它发挥的地方

三件事，按依赖顺序：先证明图是前缀的，再用度匹配 null 重测可达集，最后把
「图可能起作用」的决策单独圈出来。

## 0. 前缀性自检（做任何解释之前）

`g1_probe.task_rows()` 在把决策行 append 进 `out` **之后**才更新 `hist_edges`，
所以第 t 个决策看到的边只来自第 1..t−1 段。逐条核对过：

```
边数与前缀非特殊相邻对不符的决策：0 / 322
```

顺带两个刻画机制的数字：REVISIT 决策里 **82%** 的 `(prev, gold)` 这条转移在前缀里
出现过；**70%** 的决策里可达集真的小于候选集。所以 G1 的先验没有偷看当前这条边，
后面的数才值得读。

## 1. 之前的「打乱图」打乱错了东西

G1 的 `shuf` 条件把计数在一组**固定的边 key** 上做置换。key 没动，
`N⁺(n_prev)` 就没动——本来合法的后继仍然合法，变的只有权重。所以
`真图 − 打乱图` 回答的是「转移频次有没有用」，而不是「可达集本身有没有用」。

G1b 换成 **configuration model 双边交换**：反复取两条边 `a→b`、`c→d`，
改写为 `a→d`、`c→b`。每个节点的出度和入度都精确不变，被破坏的只有
「哪个后继属于哪个前驱」这一件事。

n=116（REVISIT 且已见节点 ≥2 且 prev 存在），只用先验排序，无视觉、无语言模型：

| 先验 | top-1 | 期望排名 |
|---|---|---|
| U 均匀 | 41.8% | 1.81 |
| F 节点频率（不看 prev） | 30.8% | 1.98 |
| **Rt 真可达集（集内等权）** | **80.8%** | **1.26** |
| Rs 度匹配打乱（双边交换） | 44.0% | 1.79 |
| Rs2 度匹配打乱（入度加权抽样） | 41.1% | 1.82 |

| 对比 | Δ | 95% CI |
|---|---|---|
| **Rt − Rs** | **+36.8%** | [+21.0%, +49.5%] |
| Rt − Rs2 | +39.8% | [+24.3%, +52.5%] |
| Rt − F | +50.0% | [+28.8%, +64.9%] |
| Rs − U | +2.2% | [−7.1%, +11.3%] |
| F − U | −11.0% | [−19.3%, +1.6%] |

`Rs − U` 跨 0 是这张表里最重要的一行：度匹配打乱之后，可达集**一点都不剩**。
信号全在成员身份上，不在出度、入度、节点频率或这一项的形状里。

只取可达集真正有区分力（`0 < |N⁺| < |V_<t|`，81 个）的子集：Rt 到 **97.5%**，
`Rt − Rs = +53.9%` [+39.2, +70.7]。

## 2. 但机制是退化的

`|N⁺(prev)|` 的分布把话说死了：

| \|N⁺\| | n | Rt top-1 | gold ∈ N⁺ |
|---|---|---|---|
| 0 | 26 | 39.4% | 0.0% |
| **1** | **79** | **98.7%** | 98.7% |
| ≥2 | 11 | 50.0% | 100% |

68% 的决策里 prev 只有一个记录过的后继，而它 98.7% 就是答案。Rt 奖励的规则是
**「上次从这里去了哪，这次还去哪」**——`prev 的最后一个后继原样重复` 单独就命中
81/116 = 69.8%。真正需要图去仲裁的（`|N⁺|≥2`）全库只有 **11 个**，在那 11 个上
Rt 只有 50.0%，与均匀持平。

所以 +36.8 不是测错，是**测量对象太稀缺**。这批录像的转移图近乎链式。

## 3. 一个必须更正的旧数：名字序平局

之前报的 top-1 用 `sorted(candidates, key=(-score, name))` 打破平局。
`event_id` 按首次出现编号，109/116 个决策的候选表本身就是这个顺序，
所以「名字序」实际上是一个免费的先验：**偏好最早见过的节点**。

| 先验 | 名字序平局 | 随机平局期望 | 白送 |
|---|---|---|---|
| 均匀 | 50.0% | 41.8% | +8.2 |
| 频率 | 56.0% | 30.8% | +25.2 |

改成 `1/|并列首位数|` 后重跑 `g1_strata`（n=126，含 prev 为空的行）：

| 先验 | 旧（名字序） | 新（随机平局） |
|---|---|---|
| 真图（带频次） | 89.7% | 81.3% |
| 支撑集（等权） | 84.9% | 78.2% |
| 打乱图 | 86.5% | 78.2% |
| 频率 P(n) | 54.0% | **30.0%** |
| 均匀 | 47.6% | 42.3% |

两处结论翻转：**频率先验比均匀差**（−12.3% [−19.6, −1.0]，CI 不跨 0），
不是之前写的 +6.3%；**真图 − 打乱图 +3.2% 的 CI 跨 0**，转移频次的贡献不成立。
`g1_strata.py` 已改用期望估计量，旧数不再复现。

## 4. Graph-Opportunity Set

四条准入判据全部在读 gold 之前确定：

- **C1** 候选节点 ≥ 3
- **C2** 视觉模糊：`s1 − s2 < δ`，δ = 满足 C1 的决策上 gap 的中位数 = **0.0358**，
  先冻结
- **C3** `0 < |N⁺(n_prev)| < |V_<t|`，可达集必须真的排除掉东西
- **C4** 保留 NEW，否则一个从不回答 NEW 的系统也能刷分

三种难度，分型只用 gap / 可达集 / 视觉 argmax，不用 gold：

| 类 | 定义 | n | 录像 | NEW | 视觉 top-1 | 可达集 top-1 |
|---|---|---|---|---|---|---|
| A | 视觉决定性（负对照） | 31 | 14 | 32% | 58.1% | 53.2% |
| B | 视觉模糊 + 图有区分力 | 9 | 7 | 0% | **100.0%** | 88.9% |
| C | 视觉与图冲突 | 8 | 6 | 12% | **0.0%** | 87.5% |

**C 型是唯一有诊断力的一类**：视觉 argmax 落在可达集之外，8 条里图赢 7 条。
但 8 条全部 `|N⁺|=1`，所以「图纠正视觉」在这里仍然等于「上次的那个后继重复了，
而视觉认错了」。

**B 型没起到作用**：按 gap 中位数定义的「视觉模糊」根本没有选出视觉会错的案例
（视觉 100%）。gap 在这个尺度上不是可用的歧义代理。这是 C2 的失败，
不在事后调 δ——调了就是拿结果造 regime。

产出率：49 条录像 → B 型 9 个（0.18/录像）、C 型 8 个（0.16/录像）。
按这个速度凑到各 60 个要 **326 / 367 条同类录像**。但低产出不是抽样问题：
`|N⁺|≥2` 全库只有 11 个。要让 B/C 变多，必须挑**本身会在同几个状态之间来回切换**
的录像，而不是多拍同类的链式任务。

## 5. 研究问题的重述

不是「图能不能打败视觉」，而是 **graph-constrained visual state tracking**：
视觉提议，可达集约束，A 型留在集里是为了让这个约束不是免费的。
当前数据支持这个提法（`Rs − U` 跨 0 证明约束的内容是实的），
但不足以测量它（能让约束非平凡的决策只有 11 个）。

下一步是采集判据，不是新模型。
