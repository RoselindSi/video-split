# U1 memory 内容打乱对照（2026-10-16）

配置 configs/graph_u1_memory_null.json；脚本 scripts/graph_u1_memory_null.py；结果 results/graph_u1/u1_causal_memory_null.json。
20 个固定种子，使用因果快照、训练折校准后的 B 参数。所有参数沿用真实 memory 上内层选择结果，未按测试 null 重调。

## 干预与限制

对每个决策，在当前可见的 known-state 候选中双射置换后继标签，源身份及每源后继数量、边计数保持不变，NEW 和无出边均匀回退保持不变。cache 与 support 共用置换。
这是条件于当前前缀的内容干预，不保证各时间点的置换能组成一条连贯在线历史；也不是新的训练/方法比较。
实际约 47.7% 边目标被改变：候选很少时置换有较高概率保留原身份。保留这些随机恒等情况，不事后筛除。

## 修正研究结论

此前 B 相对 V/P 的 +1.24pp 不足以证明其利用了正确 successor identity。当前真实−打乱无法区分，而随机内容也能产生接近的增益。
不能说“belief 已经恢复了可部署的 transition signal”。当前最窄解释是：某些 soft prior 调整了已知状态/NEW 的决策边界；具体机制仍待验证。不能据此声称历史信息不存在，旧 G1b 与此处查询接口/任务参数不同。
四题审计中的一个例子仍展示了正确前驱的非 top1 概率可以改变答案，但个例不能代替 aggregate content-null 证据。

## 阶段决定

U1 constructive-method 证据尚未通过，不启动 full-online 写入或复杂模型。保留 point/belief、校准、因果快照、cache、内容 null 的完整结果。
若继续，只做小型机制分解：候选无关的固定 NEW penalty / 已知状态统一偏置（训练折选参）能否复现增益。该项用于解释现象，不用于在同一反复查看的 benchmark 上继续寻找论文主方法。
