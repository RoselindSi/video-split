先判每一段是什么 —— 按这个顺序问，不要跳步

  第一步  能不能确定一个被作用、或者被搬动的具体物体？
          不能  →  特殊状态（等待 / 跟随 / 巡视 / 一般位移 / 遮挡 / 空闲）
          能    →  进第二步

  第二步  看不看得到结果？（放下、送达、移交，或者进入后续操作）
          看得到  →  交互节点
          看不到  →  不确定

1. 交互节点：能确定物体、看得到动作、看得到结果。三样都要有。
   「看到的结果」和「推测的目的」现在是两栏。结果栏只写你看见的；
   看不到结果就写「无可观察结果」，不要留空也不要用推测去填。
   推测的目的可以写，但它不能让一段成立为交互节点。

2. 特殊状态：等待、跟随、巡视、一般位移、遮挡、空闲。照样占时间轴，不要删。
   【注意】「一般位移」指的是**没有任何物体被作用**的移动。
   手里拿着一个能看清的东西在走，**不算一般位移**——它有物体，要走第二步。

3. 不确定：能确定物体、看得到动作，但**看不到结果**，判不出它是独立的一件事
   还是别的事中间的一步。判不了就选它，并写清看到了什么、缺了什么。
   典型情形：拿着某物在走，但看不到送到哪、也看不到拿去干什么。
   这种要选「不确定」，不要选「特殊状态 / 一般位移」。
   「不确定」是正式取值，不是没填完。宁可标它，也不要猜一个。

【改了】重复只有一种记法
4. 同一交互状态内部的连续重复不切段，勾「这一段里面有反复」。
5. 只有看得到完成 / 放下 / 重新开始时，才切开成同一个事件的下一次（A → A）。
6. 判不出中间有没有完成证据时标「不确定」。不要默认合并，也不要默认切开。

【改了】持续的等待必须单独切出来
7. 交互内部的短暂停顿（换手、看一眼、调整姿势）留在该节点内，不切段。
8. 持续、能看出起止的独立等待（等别人做完、等设备），必须单独切成
   特殊状态 / 等待，不许并进前后的交互节点。
   判据：这段时间里没有对任何物体施加动作，且有明确的起止。

运输看三条各自的证据
9.  物体能不能确定 / 看不看得到主动取得移动交付放置 / 有没有看到送达或进入后续操作。
    三条都有是交互节点；前两条有第三条无是不确定；物体不明或纯位移是特殊状态。
10. 如果你是靠这一段结束之后才出现的画面下的判断，请勾「用到了本段结束之后的证据」。
    勾了不扣分，这只是记录——模型在线预测时看不到后面。

任务
11. 每个交互节点归到一个任务，并写清凭什么（同一个工件 / 设备 / 工位 / 物料）。
12. 一个任务只有一个节点也成立；只做一遍不回到起点，也算一个完整任务。
13. 出现环不等于同一个任务。「炒菜 → 扫地 → 炒菜」是回到原任务，不是合并。
