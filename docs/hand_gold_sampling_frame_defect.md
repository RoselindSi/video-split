# 抽样网格有两个缺陷，都让系统显得更好（2026-10-12）

扩标到 10 条录像时，建第 4-10 条的页面，两条录像排出 0 个抽样帧。
查出来不是这两条特殊，是网格的定义一直是错的 —— 而前三条**靠巧合**躲过去了。

---

## §1 缺陷一：网格起点对齐在 detect2 首帧

```python
lo, hi = fs[0], fs[-1]                      # fs = detect2 里有框的帧
return [f for f in range(lo, hi+1, stride) if f in set(fs)]
```

跑的那个窗口是 400-799。十条录像里八条的 detect2 首帧恰好是 400，于是网格
排成 400/410/420…，和帧号对上了。另外两条不是：

| 录像 | detect2 首帧 | 排出的网格 | 结果 |
|---|---|---|---|
| 153159 | 415 | 415/425/435… | 与 400 对齐的帧**一个都对不上** → 0 帧 |
| 015550 | 412 | 412/422/432… | 同上 → 0 帧 |

八条对上了是巧合，不是设计。靠巧合成立的网格还有第二个后果：
**不同录像的网格可以互相错开，gold 之间不可合并**。

**改法**：网格起点 = 跑的那个窗口的起点（`--grid-start`，默认 400），
与 detect2 无关。

---

## §2 缺陷二：网格被「这一帧有没有检测」过滤掉了

`if f in set(fs)` 这一句把检测器一个框都没出的帧从页面上删掉了。
那正是「手在画面里但没被检到」的帧 —— **是这份 gold 要测的缺陷本身**。

153159 上这一条静默扔掉了 37 帧里的 **16 帧**，而且这 16 帧是连续的一段
**470-610**。打开看过：那一段镜头贴在车身上，手确实不在画面，所以标注者
会标「不在画面」。但那是**标注者的判断**，不是网格替它做的判断。

后果的量级：在旧网格下，分母悄悄变成了「检测器出过框的帧」，
于是「覆盖率」测的是 *在检测成功的前提下* 的跟踪质量，而不是端到端的手部连续性。
用户的目标是「自己的手的稳定追踪」，一帧里手可见却没被检到，对这个目标就是失败。

**改法**：有图就进网格，候选为空时标注者自己画或标「不在画面」。

---

## §3 还有一个没法改的：帧库本身是模型派生的子集

帧来自 `nothand_bank_e2e10`，那是为了采非手候选建的库，不是完整帧转储。
十条录像在 400-790 的 40 格网格上有图的比例是 **0.55 到 0.93**：

| 录像 | 有图 | present_rate |
|---|---|---|
| 153159 | 37 | 0.93 |
| 134748 | 34 | 0.85 |
| 143303 / 063732 | 32 | 0.80 |
| 145525 | 31 | 0.78 |
| 015550 | 26 | 0.65 |
| 100512 | 22 | 0.55 |

而「有图」和「有检测」几乎重合（十条里八条完全相等，153159 差 16 帧、
100512 差 1 帧）。也就是说**缺的帧基本就是检测器没出框的帧**。

原始 cam3 帧在服务器上已经没有了（找遍 /workspace 与 /shared，
只剩这个库和带判定叠加的 debug 渲染，后者不能用于标注）。所以：

> **在现有帧上算出的覆盖率是上界，不是估计。上界的紧度就是 present_rate。**

这一条写进了页面构建的输出和本文件，不靠记忆。
`present_rate` 低的录像（100512 的 0.55）要单独看，不能和 0.93 的混在一起读平均。

## §4 顺带修掉的第三个：没露过面的手被算成跟丢

153159 整条录像只有一只手露过面。另一只的 `visible_frames = 0`、
`coverage = nan`，而 `nan >= x` 是 False —— 不排掉的话它会被记成一次跟踪失败，
于是一条「唯一那只手跟得不错」的录像报成 1/2。

**没出现的手不是跟丢的手，它在这条录像里根本不是一只手。**
`headline` 现在把 `visible_frames == 0` 的手排出分母，并单独报排掉了几只。
自检加了这个用例。

---

## §5 这三个缺陷的共同形状

三个都让系统显得更好，而且都不会报错：

- 网格对齐错 → 两条录像 0 帧（这个会被发现，因为页面是空的）
- 网格被检测过滤 → **静默**，只是分母变小
- 没露面的手进分母 → **静默**，只是分母变大

能被发现的那个反而是最无害的。这个项目里同一个形状已经出现过多次
（暴露率分母、census 抽样框、学生训在全景图跑在原始帧），
共同点都是**分母由被测对象自己决定**。
