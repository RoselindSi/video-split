# Branching 采集判据：现有语料里几乎没有，而且原因是可控的

G1b 之后的结论收成两句：

> 这批数据验证的是**确定性后继记忆**（previously observed successor support），
> 不是 branching graph reasoning。后者在现有语料上**没有被测过**，
> 因为可测的样本只有 2 个。

本文把「该补多少、该拍什么」变成两个可数的量。

## 1. 现有语料的三类产量（严格前缀，60 条标注 / 49 条有决策）

| 类型 | 定义 | n | 录像 |
|---|---|---|---|
| G-simple | `\|N⁺(A)\|=1` | 194 | 34 |
| **G-branch** | `\|N⁺(A)\|≥2` 且未穷尽候选，历史节点 ≥3 | **2** | 2 |
| G-novel | gold ∉ `N⁺(A)` 且 `N⁺(A)` 非空 | 9 | 9 |
| （无） | `N⁺(A)` 为空，或支撑集穷尽候选 | 126 | 49 |

交叉表：branch∧novel = 0，branch∧¬novel = 2，¬branch∧novel = 9。

## 2. 不是「来得太晚」，是真的没有

按你的前缀原则，`A→B …… A→?`（`A→C` 在测试点之后才出现）不算 branching。
所以要分清两种情况：

```
整条录像上出度 >=2 的节点：      9 个（9 / 49 条录像）
在某决策点前缀里就出度 >=2 的：   4 个
差额（分支存在但来得太晚）：      5 个
```

差额只有 5。**延长录像不解决问题**，这批录像的转移图本身就是近乎链式的。

## 3. 两个可分离的杠杆

把产量拆成「机会 × 兑现」：

- **机会** = 被离开过 ≥2 次的节点数（它才**可能**分叉）：全库 55 个，0.92 个/录像
- **兑现率** = P(后继不同 | 被离开 ≥2 次) = 9/55 = **16.4%**

也就是说，即使一个节点被重访，**83.6% 的情况下它还是去同一个地方**。
这就是「近乎确定性」被直接测出来的样子。

兑现率随节点数上升：

| 录像的节点数 | 录像 | 有机会节点 | 真分叉 | 兑现率 |
|---|---|---|---|---|
| 1–2 | 35 | 26 | 3 | 12% |
| 3 | 8 | 9 | 1 | 11% |
| 4 | 11 | 19 | 4 | 21% |
| ≥5 | 2 | 1 | 1 | 100%（n=1） |

## 4. 为重复动作而拍的那一批，恰好拍反了

| 批次 | 录像 | 段/录像 | 节点中位 | revisit/录像 | 有机会节点 | 真分叉 | 兑现率 |
|---|---|---|---|---|---|---|---|
| mosaic_complement | 30 | 5.3 | 2 | 3.1 | 14 | 7 | **50%** |
| repeated_actions | 30 | 7.3 | 2 | 5.2 | 41 | 2 | **4.9%** |

`repeated_actions` 机会多 3 倍、兑现率只有十分之一。原因是「重复同一个动作」
产生的是 `A→B→A→B` 的来回摆：revisit 拉满，但出度恒为 1。
`mosaic_graph_0008` 是极端例子——12 个决策、11 次 revisit、**2 个节点**、0 个分支。

**所以 revisit 数不是选片判据。** 分箱验证过：`revisit>=7` 那一箱 branch/录像 = 0.00，
产出最高的是 `revisit 4–6`（0.18/录像）。

## 5. 采集判据

绑定约束是**节点数**，不是重复次数。两批的节点中位数都只有 2，
而 `|N⁺|≥2` 至少需要一个节点被访问两次、且两次之后去了不同地方——
在只有 2 个状态的录像里这在结构上不可能。

要求：

1. **每条录像 ≥5 个不同的 interaction node**（当前中位 2，这是唯一的硬约束）
2. **不要下「重复同一个动作」的指令**，它主动破坏 branching
3. 目标结构是 `A→B→A→C→A→D`，不是 `A→B→A→B`
4. 兑现率 50% 不是假设，`mosaic_complement` 已经做到

规模换算（目标 50 个 G-branch 决策）：

```
同分布再拍（0.92 机会/录像 × 16.4%）      → 约 333 条
选片到 3 机会/录像 × 50% 兑现             → 约  33 条
```

十倍差距全在选片上。任务类型（装配/分拣/打包/多步清洁/维修）本身不是重点，
重点是它们更容易产生多状态之间的往复。

## 6. 下一阶段的主实验（数据到位后才跑）

在新的 branching set 上比三个条件，分三类报告：

| | V0 纯视觉 | Vreach 视觉 + 真可达集 | Vshuffle 视觉 + 度匹配打乱 |
|---|---|---|---|
| G-simple | | | 已知容易，对照 |
| **G-branch** | | | **主测试：Vreach > Vshuffle 才算成立** |
| G-novel | | | 图先验不能压死视觉证据 |

打分器用软融合，不用 hard mask：

```
S(n) = S_visual(n) + λ · 1[n ∈ N⁺(prev)]
```

因为 G-novel 必须允许 `n ∉ N⁺(prev)` 在视觉证据够强时仍被选中。
加权转移概率 `P(B|A)` 不再作为核心模型——`真图 − 打乱图` 的 CI 已经跨 0。

如果 G-branch 上仍然 true ≈ shuffled，结论就是：
**图的价值只来自记住近乎确定的转移，没有进入更一般的拓扑推理。**
