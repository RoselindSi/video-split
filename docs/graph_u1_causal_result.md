## 正确解释

乐观接口中的前驱 top1 98.4% 降为因果快照接口约 74.0%；不能把原先 point 80.75% 作为同任务的在线结果。
P 在五折都选 lambda=0，说明目前内层评估更倾向关闭 point memory。B 有微小正信号；PG/BG 没显示额外收益。
单纯沿用 P 参数校准时所有 lambda 为零，对照必然无差别，该结果保留在 u1_query_causal_calibrated.json，仅作退化检查，不能说校准没有作用。主表使用重新在内层选参后的结果。
