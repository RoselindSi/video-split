# 佩戴者区域标注（双目）

## 标什么

把画面**一分为二**：一侧是佩戴者自己的手会出现的区域，另一侧是别人的。
不是把每只手圈出来 —— 是画一条**横穿整个画面的分割线**，线的一侧（绿色填充）
= 自己的手那一侧。

判断标准很简单：**同事的手落在线的另一侧了吗**。落在里面就是画错了。

## 为什么要标两只眼

`cam34.mp4` 是 cam3 和 cam4 并排，两台相机基线 9.3 cm。佩戴者自己的前臂在
0.2–0.3 m，那个距离上左右眼看到的位置差几十到一百多像素；对面工位的长凳在几米外，
差几乎是零。所以**同一条线在两只眼里不是平移关系** —— 线的近端和远端要挪的量不一样。
只标一只眼，另一只眼就完全没有区域可用，而滤波是两只眼都要跑的。

## 怎么标

1. 在**任意一只眼**里按住鼠标拖一条线。画到该眼画面边缘就自动收笔，两端会自动延到边界。
2. 另一只眼**立刻得到一份平移过来的拷贝**（虚线 + 半透明 = 拷贝的，不是你画的）。
3. 看拷贝对不对。不对就用 `[` / `]` 左右推（按住 shift 一次推 10 像素）。
   **推的量会被记住**，下一条线的拷贝就从这个视差开始，越标越省事。
4. 拷贝实在对不上（比如线的两端需要挪不同的量），就在那只眼里**直接重画一条**。
5. 放着播。等到线**不再对了**（人侧身、转头、工位移进画面），停在那一帧重新画一条。
   中间的帧会在两个关键帧之间自动插值。
6. 线一直对就**不用打关键帧**。只在它开始不对的地方打。

## 键

| 键 | 作用 |
|---|---|
| 按住拖拽 | 在光标所在那只眼里画曲线 |
| `[` `]` | 把当前这只眼的线左右推（shift = 推 10 px），同时更新记住的视差 |
| `x` | 从另一只眼重新拷一份过来 |
| `f` | 翻转**这只眼**哪一侧是自己的 |
| `1` `2` | 切换当前操作的是左眼还是右眼（点一下那半边画面也行） |
| `k` | 两只眼一起在当前帧打关键帧（= 看到这里线还是对的） |
| `d` | 删掉**管着当前这一刻**的那个关键帧（两只眼一起，不必停在关键帧上） |
| `u` / `ctrl+z` | 撤销（60 步） |
| `shift+C` | 全清 |
| 空格 | 播放／暂停 |
| `,` `.` | 前后一帧 |
| `←` `→` | 前后一秒 |

进度条可以**拖着拉**。上排绿色竖线 = 左眼(cam3)的关键帧，下排蓝色 = 右眼(cam4)；
半透明的那些是拷贝来的、你还没核过的。

## 数据怎么交

**从服务器打开的**（地址栏是 `http://...`）：随手标随手自动存草稿
（每次改动 4 秒后），标完点一次**提交**。提交后右边会显示存到哪了，
比如 `已存到 databag-26_0824_160752/R0824_160752__你的名字__final_....json`。

名字在有账号时是登录身份、锁死不能改；本机自己跑时默认用系统用户名，可以改。

**「另存一份 JSON」不是提交**。它是浏览器下载，只会落在你的**下载目录**里，
网页没有办法把文件存到别的路径——这是浏览器的限制，不是工具的。
联网用的时候不需要它，点提交就已经写到服务器上了。

**离线用**（直接双击 html 打开，地址栏是 `file://`）：提交按钮是灰的，
标完点 **另存一份 JSON**，把下载目录里的文件发回来。html 和 mp4
必须在同一个文件夹里，否则是黑屏（会有红色提示）。

标注过程存在浏览器里，关掉标签页再打开不会丢；但换电脑、清缓存会丢，
所以**别只靠它**。

## 导出的东西

每只眼一套，坐标是**那只眼自己的原始分辨率像素**（1920×1520），不是屏幕上的。
每个关键帧带：

- `curve` — 64 个点的分割曲线
- `own_polygon` — 自己那一侧的闭合多边形（可以直接拿来判断一个点在不在里面）
- `own_side_point` — 该多边形的中心，用来确认方向没搞反
- `src` — 这条线怎么来的：
  - `drawn` = 在这只眼里**真画**的
  - `held` = 之前画的线，人看到这一帧确认还对
  - `copied` = 从另一只眼平移过来的，**没人真的看过**

`src` 是有用的：下游要只看人真画过的线时，按它过滤，
拷贝来的不能当成第二次独立观测。
