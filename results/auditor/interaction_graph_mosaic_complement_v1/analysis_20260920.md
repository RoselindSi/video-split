# Hand-mosaic complement annotation analysis

Analysis date: 2026-09-20

## Scope and validation

- Manifest: 30 videos, 3,202.967 seconds (53.38 minutes).
- All 30 videos have a confirmed final annotation with complete, gap-free time coverage.
- The directory contains 41 final snapshots because seven videos were submitted more than once. All statistics below use the latest `saved_at` value for each video.
- Raw annotation total: 78 local nodes and 174 segments.
- One segment is shorter than one second: `mosaic_graph_0011`, segment 12, 46.6-47.5 seconds (0.9 seconds). It has the same event on both sides, so collapsing consecutive identical states removes any topological effect.

## Comparable action graph

For the comparison below, exact labels `特殊事件` and `看不到内容` are excluded from the derived action graph. The annotator confirmed that all `特殊事件` spans can be removed from action analysis. Source annotations remain unchanged for provenance.

- Action nodes: 69.
- Videos with more than one action node: 20/30.
- Action transition occurrences: 51.
- Adjacent same-state transition occurrences: 79.
- Within-segment repeat occurrences: 22.
- Videos with either kind of self-loop evidence: 22/30.
- Videos that return to an earlier action after an intervening action: 7/30.
- Repeat pattern categories:
  - Self-loop only: 17 videos.
  - Self-loop and return cycle: 5 videos.
  - Return cycle only: 2 videos.
  - Neither: 6 videos.

Raw self-loop counts are not annotation-invariant. Among the 30 videos, 12 encode repetition only with the within-segment checkbox, six only with adjacent same-state segments, four use both, and eight use neither. Presence/absence is comparable; raw occurrence counts are not.

## Excluded special content

- `特殊事件`: eight local nodes, ten segments, 248.50 seconds across eight videos.
- `看不到内容`: one 17.233-second video (`mosaic_graph_0027`).
- Together these account for 265.73 seconds, or 8.30% of the complement duration.

The longest excluded spans are `mosaic_graph_0017` (68.7 seconds) and `mosaic_graph_0001` (57.7 seconds plus a 6.0-second span). They are retained only in the source timeline and are not nodes or edges in the derived action graph. ## Label normalization flags

These labels should be reviewed before semantic clustering:

- `mosaic_graph_0002`: `旋下风扇头` and `拆风扇头` may be two instances of one canonical state or two distinct fan subassemblies.
- `mosaic_graph_0008`: `给一根电线` is incomplete and does not name the machine operation or result.
- `mosaic_graph_0005`: `安装零部件` is too generic for cross-video matching.
- `mosaic_graph_0020`: `安装设备1` is too generic and uses a local placeholder.
- `mosaic_graph_0016`: `用机器处理一个黑色物件` and `用喷枪处理一个黑色物件` need the object/result named if visible.
- `mosaic_graph_0003`: `reposition人和机器的位置` mixes languages.
- `mosaic_graph_0014`: `整理碗筷杯set` mixes languages.
- All eight `特殊事件` nodes are excluded from semantic clustering by policy.

## Main conclusion

The complement achieved its primary purpose: it added assembly, wire processing, stocking, weighing/packing, cleaning, craft work, transport, waiting, and coordination episodes beyond the first repeated-action pool. It does not remove the need for the first batch, because the first batch supplies substantially more return-cycle structure.

Before building the joint semantic graph, preserve the current local nodes and add a separate `procedure_group` layer. Normalize the remaining action descriptions, then group by goal, object, and result while retaining the original fine-state transitions.
