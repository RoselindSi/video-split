## 概率检查

五折均选择网格下限 0.01。留出前驱 ECE 从各折 0.45–0.53 降到 0.003–0.058；NLL 从 0.61–0.89 降到 0.003–0.21。前驱 top1 始终为 98.37%。平均 gold mass 从 0.484 升为 0.962，entropy gate 从 0.026 升为 0.885。
这说明前一轮差距很大一部分与未校准的查询分布过平有关，不能概括为 belief query 无效。

## 不可忽略的边界

- 前驱 observation 本身包含在 oracle 分组的前缀 prototype 中，存在自包含的乐观偏置。校准训练和测试都使用这个接口，因此温度趋近 hard point 并不意外。
- 当前前驱 gold 始终在 oracle 前缀里；没有 NEW 前驱真值。该校准不覆盖开放集在线 NEW。
- 网格下限命中不意味着最优温度已经确定；不基于外层结果扩展网格追分。
- 门控仍未提供可证实的额外收益，不启动复杂 full-online 写入实验。

## 下一步必须先修正实验接口

构建严格因果的前驱 posterior：在上一段到来之前的 prefix 上计算，保存当时的候选、NEW 质量和 posterior；不能用包含上一段及其 gold 分组的新原型重识别它。
先在训练录像处理前驱 NEW 质量如何映射到当前 oracle-memory 查询（oracle 对齐与真正预测身份分开报告），再评估校准、point/belief/gate 和噪声。
现有结果只支持“乐观 oracle-aligned 接口下，概率校准可恢复多数 belief 损失”，不支持“在线 memory 已修复”，也不支持“prototype 是唯一瓶颈”。
