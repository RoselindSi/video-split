先判每一段是什么（这是 v2 新加的第一步）
1. 交互节点：有被作用的具体物体、有施加的动作、有可观察的变化。三样都要有。
2. 特殊状态：主要是等待、跟随、巡视、一般位移、遮挡、空闲。它照常占据时间轴，不要删掉，
   也不要把它两边的段接起来。
3. 不确定：看得到携带物体或位移，但这个窗口里判不出它是独立的目标，还是别的任务里的
   附带动作。判不了就选它，并在补充说明里写你看到了什么、缺了什么。

判断落在你在视频里看到的东西上，不落在描述写得细不细。

切段规则（和上一轮相同）
4. 同一次继续做，包括来回擦、反复拧：不要切段，勾“这一段里面有反复”。
5. 同一种事已经结束、之后重新开始：在真正开始处切开，右边继续选原事件。
6. 目标换了：在新目标真正开始处切开，右边新建或选择另一个事件。

任务
7. 每个交互节点都要归到一个任务，并写清凭什么判它属于这个任务
   （同一个工件 / 同一台设备 / 同一个工位 / 同一批物料）。
8. 一个任务只有一个节点也成立；只做一遍、不回到起点，也算一个完整任务。
9. 出现环不等于同一个任务。「炒菜 → 扫地 → 炒菜」是回到了原来的任务，
   不表示炒菜和扫地是同一个任务。

需要你留意的
10. 不确定是一个正式选项，不是没填完。宁可标不确定，也不要猜一个。
11. 没见过的状态、没见过的任务、没见过的转移，都可以直接新建。
