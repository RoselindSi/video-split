## 3. 跨录像也没有

`000435 / 000416 / 000438` 是三条独立录像做同一件事（保鲜膜 + 碗，各 4 个节点）。
把本地标号按描述归到统一语义后：

```
000435   扔 盖 整 揭 扔 盖 整 揭 扔 盖
000416   整 揭 扔 盖 整 揭 扔 盖 整
000438   盖 整 揭 扔 盖 整 揭 扔 盖
```

三条是**同一个环** `盖→整→揭→扔→盖`，只是三分钟窗口切在不同相位。把三张图并起来：

```
盖 -> 整      整 -> 揭      揭 -> 扔      扔 -> 盖
跨录像最大出度：1
```

所以「分叉也许存在于录像之间而不是录像之内」这条退路，在这批数据上也是关的。

## 4. 选片 proxy 是反的：r = −0.46

窗口是按旧数据集自由文本标签的「物件族切换」挑的。这是它第一次被真标注检验：

| video | proxy 预测切换 | 真实节点数 | 真实切换 |
|---|---|---|---|
| recording_000169 | **16** | **1** | **0** |
| recording_000330 | 4 | 1 | 0 |
| recording_000142 | 4 | 1 | 0 |
| recording_000435 | **2** | **4** | **9** |
| recording_000416 | 2 | 4 | 8 |

**相关系数 −0.46。** proxy 预测最高的那条真实只有一个节点：旧标签在洗水槽那段
反复漂移措辞，被物件族判据读成了切换；而真正有四个节点的保鲜膜段，因为物件
始终是「保鲜膜 + 碗」，被判成只切换 2 次。

「动词会漂、物件不漂」这个想法在筛选上不成立——**物件不漂恰恰意味着物件
分不出节点**。

## 5. 合同字段的洞

| 字段 | 用量 |
|---|---|
| `confidence` | 117/117 全是 `high`，`uncertain` **零使用**（第三次） |
| `retrospective_confirmation` | **零使用** |
| `evidence_timestamp` 落在该节点第一段**结束**之后 | **26 / 36 个事件** |
| `inferred_goal` | 零使用（设计上可选） |
| 任务簇 | 每段恰好 1 个，所有节点都在里面 |

第三行是真问题：事件 A 被标在 `[0, 14.2]`，而它的 `evidence_timestamp` 是 149.2 —— 
节点在它的第一段结束之后 135 秒才拿到证据，按定义这就是 retrospective，但没有勾。
26/36 都这样，所以这不是个别失误。（分界是第一段的**结束**不是开始：段内出现的证据是正常的。）最可能的原因是页面上那个
**「用当前播放位置」按钮**：它记的是标注者当时的播放头，不是证据出现的时刻。
这个 affordance 要改，否则 E4 的 prefix-only 判据拿不到可用的证据时间。

任务簇在三分钟片段上是退化的——一段只做一件事，簇层面没有信息。

## 6. 这意味着什么

现在有三次独立测量：

| 来源 | G-branch |
|---|---|
| 最早 60 条 release | 2 |
| 471 条旧标注池（交错判据） | ~5 |
| **15 段人工挑选 + v2.1 重标** | **0** |

结论不是「包没打好」，而是关于这个域的事实：

> **在这个标注粒度上，第一视角手部操作录像的交互图是确定性的环。**
> 图的预测力是真的、而且是完全的，但它是 transition memory，不是拓扑推理。

graph-constrained visual state tracking 这条线**在这批数据上无法被检验**，
因为约束从来不是非平凡的：知道 n_prev 就完全决定了 n_next。

需要你定方向，三条路：

1. **收口成负结果**。把「图的贡献 = 确定性后继记忆，branching reasoning 在
   自然手部操作数据上不可测」写清楚，连同三次测量。这是个干净的限制性结论。
2. **换粒度**。标注者选的是自然粒度（3 分钟 1–4 个节点）。更细的粒度也许有分叉，
   但那要改合同，而且更细的节点更可能是同一动作的相位。
3. **换任务形态**。真正会分叉的是**有选择的**任务：分拣（按类别去不同去处）、
   排障（看状态决定下一步）、有中断的流程。这批数据里全是固定流程的重复操作。
   这需要重新采集，不是从现有池子里筛。

我的建议是 1 + 3：先把负结果写死，同时按「有选择点的任务」重新定采集判据——
而且这次的判据必须**在新标注上**验证，不能再用旧标签的 proxy。
