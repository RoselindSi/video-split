## §2 四个几何特征里只有一个活着

决策点内 macro AUC（越高越能把同一只手排在前面）：

| 特征 | 决策点内 AUC | 读法 |
|---|---|---|
| **中心距 / 框宽** | **0.821** | 唯一有效的 |
| 匀速外推残差 | 0.618 | **比什么都不做更差** |
| 框宽比的对数 | 0.556 | 死的 |
| 时间间隔 | 0.527 | 死的 |

**匀速外推失败的原因是机械的**：间隔中位 46 帧 ≈ 1.5 秒，用最后两帧估的速度
撑不过 1.5 秒的手部运动，外推把噪声放大成中位 958 px 的残差（画面宽 1920）。

→ **「手是连续运动的，所以用运动模型连接它」这个假设被推翻了。**
断裂之后的时间和运动不可预测；**同一断点附近的空间位置仍然带信息**，仅此而已。

## §3 归一化的作用，以及它证明了什么

距离门是 `d <= 3.0 * width_a`，是**相对**框宽的阈值，所以框大的录像允许更大的
绝对距离。不归一化时：

```
pooled AUC      0.879
录像内 macro     0.619
决策点内 macro   0.821      <- pooled 比它还高 = 录像间构成差异在帮忙
```

按 `width_a` 归一化之后 **pooled 0.822 与决策点内 0.821 重合** ——
这就是「分数跨点可比」的证据，也坐实了那 0.879 是录像间捷径
（与 `within-recording-is-the-metric` 同一形状）。

## §4 为什么挂的是阈值稳定性，不是信号强度

8 折里 7 折都选 0.361，只有留出 `063732` 那折选了 0.471，而那条录像里
**最小的负例分数恰好是 0.361**，正例中位是 0.607 —— 分布在阈值必须落的位置重叠。

逐录像 AUC 的离散度也说明同一件事：

```
0.000  0.000  0.500  0.750  0.838  0.889  0.910  0.930     中位 0.794
```

两条 AUC = 0.000（各只有 1 个正例，单看没意义，但确实整个排反了）。
**这个特征不是普遍可靠的，它在大部分录像上很好、在少数上完全失效。**

## §5 不做的事

全量数据上固定阈值 0.361 的话是「并对 18、误并未归属 1」。
看起来只要换一条更保守的阈值挑选规则（比如取各折最小值）就能过判据 ——
**但那是在测试结果出来之后改选择规则，就是在测试集上调参。**

要做的话必须重新事前注册，而且这 10 条录像已经用过了，
需要新录像才有干净的测试。这个项目为同类做法付过四次代价。


还要记住两个上限：
- 35 个决策点里 **2 个没有正例**（真后继被窗口或距离挡在候选集外）——
  任何消解器都救不了，那是召回问题不是判别问题。

  argmax 按构造就会漏掉一半。
